# 秋千跳跳：设计系统

本项目由 GLM-5.4 开发，提示词只有 README 末尾的那一句。这份文件记的是做下来的决定：想要什么、每样东西为什么长这样、玩法上的数字是怎么定出来的。

## 意图与视觉方向

一句话：**踩着云海上的一排秋千往前跳，身后有一只狼在追。**

- **玩的人要有的感受**：轻快里带一点紧张。起跳、落上去是干脆的；连着落在正中会越跳越顺；狼一出现就不能再慢慢想。
- **视觉上的一句话**：粉彩色的天空和一望无际的云海，一排鼓鼓的绿色小岛，每座岛上一棵圆滚滚的树，树枝探出岛沿吊着一个秋千。一只系红围巾的白兔站在上面，远处有粉色的樱花树和淡淡的云堤。
- **画风是“绘本黏土”**：卡通着色把明暗分成三段，所有东西带一层很轻的颗粒，轮廓是圆的、面是鼓的。颜色统一取自 `src/core/palette.js` 的一张色表：草是三种黄绿，土是赭黄，岩石是灰紫，强调色只有珊瑚红、暖黄、天蓝、丁香紫、薄荷绿五种——岛上花的颜色、秋千侧面刷的色带、绳子顶上的蝴蝶结用的都是这一座岛的强调色。界面也是同一套：奶油色的纸片、墨色的字、珊瑚红的按钮。
- **观看距离只有一档**：玩法画面宽 10.5 ～ 15.5 米（狼追近时放宽到 19.5 米），兔子不算耳朵一米来高，在画面里占十几分之一。所以细节不放在贴图上，放在轮廓、大的色块和明暗分界上；放大了看是圆滑的低面数形体，这是有意为之的。

## 玩法上的数字是怎么定的

规则全部在 `src/core/` 里，不依赖 three.js，可以脱开浏览器成千局地模拟（`src/core/bot.js` 里有一个会玩游戏的机器人）。下面的数字都是这么试出来的。

**跳跃**（`physics.js`）：重力取 22 米/秒²——是真实值的两倍多，跳起来才干脆、不飘；起跳角 46°；按得越久初速越大，1.1 秒按满，初速 6.5 ～ 15.6 米/秒；所以最远能跳 11 米左右，而秋千之间最远 8 米。落点离座板中心不到 0.14 米算“落在正中”，0.38 米以内站得稳（宽板凳是 0.83 米）；再往外、板边以内再加上半只脚（0.14 米）能踩到，但站不稳，会滑下去。

**路**（`course.js`）：一排浮岛，玩到哪儿生成到哪儿，带种子，同一局每次打开都一样。

| | 怎么定 |
| --- | --- |
| 前四个间隔 | 固定 4.6、5.0、5.2、5.2 米，先练准头 |
| 之后的间隔 | 4.3 米起，每往后一个加 0.06 米（加到第 36 个为止），再随机加 0 ～ 1.7 米，最宽 8 米 |
| 高低 | 第 6 个以后每一步上下最多差 0.55 米，整体往 0 回，夹在 ±2 米里（不这样的话会一路漂到云海底下） |
| 晃动 | 空秋千被风吹得摆开多少：前五个不晃；之后逐渐加到 23°，另有四分之一的秋千是不晃的 |
| 金色秋千 | 第 5 个起一成，落上去 +5 分，不会连着两个 |
| 宽板凳 | 一成，板宽 1.86 米，好踩 |
| 裂缝的旧秋千 | 第 14 个起一成，站上去 2.6 秒就断 |

秋千自己的摆动按真实的重力算（周期 2π√(L/g)，绳长 1.7 ～ 2.1 米，约 2.6 ～ 2.8 秒一个来回），所以晃起来的节奏像真的；兔子在空中的轨迹才是那个调快了的重力。

**计分**：落上去 +1；越过中间一个秋千直接落到下下个 +3；连着落在正中，额外加 +2、+4、+8……每连一次翻一倍，最多 +32。

**风暴狼**（`game.js`）：荡过两个秋千以后从身后 30 米处出现。速度是 1.35 米/秒加上每往后一个秋千 0.045 米/秒（封顶 2.9）；落后 34 米以上会以 2.4 倍猛追，追到 3 米以内反而放慢到 0.85 倍，留一线。离兔子不到 1 米就算追上。左上角一直写着狼还有多少米，8 米以内变红、发抖。

**难度是用机器人试出来的**。让它替玩家玩，每次落地以后先“犹豫”一段时间再起跳（模拟人在看秋千、下决心），每种手速 200 局：

| 每跳犹豫多久 | 中位数荡了多少个秋千 | 四分之一 ～ 四分之三 | 怎么结束的 |
| --- | --- | --- | --- |
| 不到 0.5 秒 | 400（上限） | — | 都没死 |
| 0.6 ～ 1.4 秒 | 166 | 137 ～ 194 | 全部被狼追上 |
| 1.0 ～ 2.0 秒 | 42 | 38 ～ 44 | 145 局被追上，55 局秋千断了 |
| 1.5 ～ 3.0 秒 | 22 | 17 ～ 25 | 109 局秋千断了，91 局被追上 |

所以这个游戏没有“终点”，玩的是节奏：手快就一路荡下去，一犹豫狼就逼近；越往后旧秋千越多，站上去等着也不行。落点带 ±0.25 米的随机误差时机器人照样不会掉——掉不掉主要看按的时机，这是“跳一跳”那一类玩法该有的手感。

## 对象决定

**秋千**是主角，也最费心。

- *是真的秋千*：树枝上隔着 0.86 米的两点各系一根绳，所以两根绳始终平行，木板在下面永远保持水平。踩偏了木板会朝那边倾一点，落地的时候绳子被拽长一下再弹回来。蹬出去的反作用力让空秋千往后甩一大下，再慢慢回到风吹的摆动。
- *样子*：奶油色的圆角木板，侧面刷着这座岛强调色的色带，绳子是麻绳色，顶上打着小蝴蝶结。金色的秋千发亮、前沿挂着两个小铃铛；宽板凳更长；裂缝的旧秋千是灰褐色的旧木头，上面一道豁开的裂缝和崩掉的一角——断的时候木板裂成两半往下掉。

**岛**：上面是微微鼓起的草地，边上一圈草皮包着、垂着几条根，往下是一圈土和一层层灰紫的岩石，收成一个尖扎进云海里。草地和草皮是圆滑的，岩石是一块块的平面（每一块深浅略有不同），一软一硬。岛面上撒着草丛、花、蘑菇和小石头，树的周围留空。约 16% 的岛上是粉色的樱花树。

**树**：一根上细下粗、有点弯的树干（带树皮的棱），根往土里扎；一大团树冠是七个鼓包的球叠在一起，上面浅、下面深；一根树枝探到岛沿外面挂秋千，枝上带着两小团叶子。树冠带“随风摆”的权重，叶尖晃得比里面多。

**兔子**：圆滚滚的白兔（不算耳朵一米来高），系一条珊瑚红的围巾，全是球和胶囊拼的。动作都是代码摆出来的：蓄力时压扁、在空中拉长、落地弹一下；耳朵是两节的弹簧，起跳和落地时会甩；围巾的飘带是一串质点做的布料模拟，风往左吹、兔子往右冲时被拖着走。蓄力足的那一跳在空中翻一个跟头。平时会眨眼，掉下去和被抓的时候眼睛变成叉。

**风暴狼**：靛蓝色，背上一道浅色，鬃毛往后倒，眼睛发黄光，咧着嘴露出牙。它踩在一朵风暴云上追——云是九团压扁的球，底下五团深的、上面四团浅的，和岛、树用同一种材质，一起被太阳照、一起投影。跑动是程序摆的奔跑姿势，追上时扑过来到兔子身上，这一下是慢动作加一记白闪。

**云**：云海是一大块平面，着色器里用噪声堆出起伏，按法线算出三段明暗；上面另有三层软片子的积云（云面上的鼓包、岛后面的中层、很远的云堤），都是真的三维位置，镜头往右走的时候各层快慢不一样——2.5D 的纵深就是从这儿来的。

## 2.5D 是怎么做的

- **玩法只有一个轴**：兔子只在 x（往右）和 y（上下）上运动，永远在 `z = 0` 这个平面上起跳和落下。岛、树、秋千、狼都在这个平面上或紧挨着它的后面。
- **镜头从侧面偏左、略高处看**：偏航 14°、俯角 14°，视野 32°。竖屏的时候偏航收到 7°、俯角 15°、看得窄一点。镜头跟着兔子，落地时轻轻一沉，狼追近时一直有一点点抖。
- **纵深分了六层**，由远到近：天空穹顶 → 远处的云堤（z −240 ～ −130）→ 远处的小岛（9 座，z −125 ～ −58，化在雾里）→ 岛后面的积云（z −70 ～ −28）→ 玩法平面上的岛、树、秋千（岛的纵深中心在平面后面 2 ～ 3 米）→ 云面上的鼓包（z −34 ～ −4）→ 镜头跟前从画面下沿探进来一点的前景云。鸟群、飘过的花瓣和叶子也是真的三维位置。
- **岛的前沿停在玩法平面后面 0.6 米**：踩空了一定是掉进空里，不会被岛面接住。

## 材质、构图与尺度

- **卡通材质**（`src/gfx/toon.js`）改自 three.js 的 `MeshToonMaterial`：明暗分成三段（背光、中间 0.58、受光），加上半球的补光、轮廓边缘一圈很淡的冷色、按世界坐标的颗粒。风把顶点往一边偏，偏多少存在每个顶点的 `aSway` 里。场景里除了云、天空、粒子和眼睛里的高光，全是这一种材质——画风统一靠的是这个，不是靠一张张调。
- **颜色**都来自 `palette.js`：天空从顶上的蓝到地平线的近白，雾是天和云海的淡蓝灰；草 `#7CC656`、`#96DB6B`、`#63B44E`，土是赭黄，岩石 `#8D88B0` 一类，树干是暖褐；兔子是奶油白，围巾珊瑚红，狼是靛蓝 `#4A4378`。
- **尺度**都按米：座板 0.86 × 0.6 × 0.09 米，兔子不算耳朵一米来高，树 3.0 ～ 3.4 米，岛半径 1.9 ～ 2.7 米，云海面在岛面下约 2.4 米。
- **构图**：画面的左缘在兔子脚下座板的左侧 3.4 米，右缘在下一个秋千的右侧 3.6 米，宽度夹在 10.5 ～ 15.5 米之间——所以兔子偏左，前面留着路；在空中的时候把起跳点和下一个秋千都框住。狼在 16 米以内时画面连续地往左放宽，到 9 米以内放到最宽的 19.5 米，把狼框进来；被追上以后镜头拉近。

## 光照与成像

- **一盏太阳**（暖白，从镜头的右前上方来）负责投影，一层半球光（天蓝在上、暖米色在下）补背光。阴影是柔和的，贴图 1024 或 2048。
- **后期只有两道**：HDR 多重采样的场景缓冲 → 最后一道（暗角、狼追近时四角发紫发暗并跟着心跳一收一放、被抓时的白闪、很轻的颗粒、饱和度提一点）→ 色调映射（Neutral，曝光 0.6）。**没有泛光**：这种画风靠的是干净的色块，要发光的地方（狼的眼睛、星星）自己带一片叠加的柔光。
- **雾**是天和云海之间的那种淡蓝灰，46 米开始、230 米化尽，远处的小岛和云堤都化在里面。

## 行为与交互

- **规则和画面分开**：`src/core/` 里只有数字，画面（`src/game/view.js`、`src/world/`、`src/actors/`）只读状态。规则以 1/120 秒为上限一步一步推进；按下和松开的事件带着它发生的时刻，推进到那个时刻再处理——所以按住多久就是多久，和帧的长短无关（这台机器通过远程桌面用时刷新率只有 32 赫兹，就是在这儿逼出来的）。
- **镜头**是三个临界阻尼的弹簧（位置 x、y 和视野宽度），追目标是硬跟，宽度放宽放窄是慢慢过去的。
- **加分和提示**飘在世界里的那个点上，镜头动了它们跟着挪。
- **自动画质**：每 45 帧看一次帧间隔的中位数，和这台机器跑出来的最快帧比，连续两次明显更慢才降一档；稳定一阵再升回去。不拿固定的毫秒数当阈值——远程桌面下刷新率封在 32 赫兹，拿 24 毫秒当线会一上来就降到最低档。
- **声音**全部用 WebAudio 现场合成：风声和一层很轻的和声做底子，隔一阵有鸟叫；蓄力时越按越高的气声，起跳的弹跳声，落地的木头声，落在正中是往上升的钟声；狼来了有狼嚎，它越近吼声和心跳越响；掉进云海、秋千断、被抓、结束、破纪录各有各的声音。
- **界面**：标题（字后面垫一团柔白的“云”）、玩的时候的分数 / 连击 / 狼的距离 / 蓄力条 / 操作提示、暂停和设置合用的一张纸片、结算卡片。手机上写的是“按住屏幕”，纸片压缩到一屏放得下。

## 运行与检视

- 双击 `index.html` 就能打开（`file://`），不需要服务器，运行时不联网。
- 地址栏的参数 `?seed=5&q=2`（`q` 是 `auto`、`0`、`1`、`2`）和 `window.__game` 给自动化留了口子：读状态、读统计、跳到第几个秋千、把狼摆到多远、把规则停住、量帧耗、把场景画进 HDR 缓冲读回来数坏像素。

## 踩过的坑

都在验证报告里记了因果，这里只留最值得记的几条：

- **泛光让半个画面变黑**：在半浮点的后期管线上加 `UnrealBloomPass`，画面有五到七成是黑的。改成不加泛光，发光的东西自己带叠加的柔光片子。
- **云带着一级级的直边**：云海是一块不透明的平面，云片伸到它下面的部分被它切平；同一团云里各张片子远近略有不同，切口的高低差几个像素，叠起来成了台阶。让云片在自己的着色器里贴着云海面的高度淡出，不再被硬切。
- **前景云把下半屏罩白**：贴着镜头飘的几朵云个头太大，飘过时用一层奶白把秋千和狼都盖住了。压到只从画面下沿探进来一点。
- **狼吼一直在响**：颤音的振荡器直接加在音量参数上，闸门关着它也在 ±0.35 之间摆，等于一直有一股很响的低频嗡嗡声，把别的音效全盖住了。改成乘在闸门后面。这事是声音检查的电平表发现的——底噪的均方根是正常值的八倍，别的音效全被它盖住了。
- **蓄力条不见了**：样式表里一条规则的尾巴上写了 `//` 注释，CSS 不认，它把下一条规则（蓄力条）的选择器一起吞掉了。
- **清理 import 清掉还在用的函数**：蓄力足的那一跳要空翻，`launch` 还在用。是画面检查里“松手以后一直停在空中”暴露的。

# 验证报告 · 运输船

这份报告只写**实际跑过、实际看过**的东西。哪些是量出来的、哪些是看截图判断的、哪些没验证，分开写。

本项目由 GLM-5.4 开发，提示词只有 README 末尾的那一句。

## 1. 环境

| 项目 | 值 |
| --- | --- |
| 机器 | Windows 11 Pro 10.0.26200，NVIDIA GeForce RTX 3080（20 GB），64 GB 内存 |
| 浏览器 | 系统 Edge，无头模式，Playwright 1.64 驱动，ANGLE / D3D11 |
| 分辨率 | 截图和验收 1280×720 或 1600×900，像素比 1 |
| 打开方式 | 全部是 `file://` 直接打开 `index.html`（仓库里的压缩版 `app.js`） |
| 显示 | 做测试时这台机器是通过**远程桌面**连着的，虚拟显示器 1920×1080 @ 32 Hz |
| 代码规模 | `src/` 39 个文件约 5900 行；`app.js` 压缩后约 0.95 MB |

## 2. 跑了什么，结果如何

| 命令 | 查的是什么 | 结果 |
| --- | --- | --- |
| `node tools/qa/node_sim.mjs` | 纯逻辑，不开浏览器：寻路栅格、12 个出生点、225 条热点间的路径、机器人跑 30 秒不卡死、会开枪换弹走动、射线命中部位、射速、换弹 | 22 项全部通过 |
| `python tools/qa/app_check.py` | 端到端：用真实的键盘鼠标事件驱动页面，逐项断言并截图 | 108 项全部通过，用时 65 秒 |
| `python tools/qa/soak.py --seconds 60` | 真实时间跑一局、乱按 60 秒，每 5 秒体检；最后切 6 次暂停 / 大厅 / 开局 | 连跑 3 次全部正常：0 个页面报错、0 个 NaN、没有人掉出甲板、粒子池没被占满、几何和贴图数量不涨 |
| `python tools/qa/perf.py` | 3 个画质档 × 2 种分辨率的单帧渲染耗时（渲染后读回一个像素逼 GPU 同步，30 帧取平均，两轮取小） | 见下表 |
| `python tools/qa/glsl.py` | 启动诊断：着色器编译错误、控制台报错、启动各阶段耗时 | 连续 8 次启动都没有报错 |
| `python tools/qa/gallery.py` | README 的 16 张运行截图 | 页面错误 0 个 |

原始结果在 `docs/evidence/`（`acceptance.json`、`soak.json`、`perf.json`）。

**端到端验收的 108 项大致是**：开局 8、界面 7、移动 / 下蹲 / 跳跃 / 碰撞 / 通路 10、视角 3、开枪与特效 6、射速 / 后坐 / 散布 3、换弹 4、瞄准 3、切枪 6、命中 / 爆头 / 计分 / 播报 6、重生与连杀 4、军刀 2、手雷 5、受击与阵亡 4、机器人 5、雷达 2、战绩板与计时 3、AWM 与开镜 7、潜伏者 1、夜晚 1、画质 2、结算 2、绘制规模 1、性能 2、实时对局与鼠标 3、暂停 / 继续 3、大厅 5。

**单帧渲染耗时**（含阴影、海水倒影、环境光遮蔽、泛光；镜头停在主甲板西侧朝东看，130 次绘制左右）：

| 分辨率 | 高档 | 中档 | 低档 |
| --- | --- | --- | --- |
| 1280×720 | 5.0 ms | 3.7 ms | 1.8 ms |
| 1920×1080 | 5.1 ms | 4.6 ms | 2.1 ms |

验收里另有一项固定在 1280×720 高档、出生舱里朝门口看时量出来的：4.1 ms / 帧，179 次绘制，约 78 万个三角形。

**在真实窗口（有头 Edge）里另跑过一次 15 秒**：用 `file://` 打开 → 真实点击「开始游戏」后指针锁定成功（`document.pointerLockElement` 是画布）→ 自动画质保持高档 → 0 个报错 → 帧率 32（和下面说的远程桌面刷新率一致）。脚本发的 Esc 不会触发浏览器自己的“退出指针锁定”，所以“按 Esc 暂停”这条路径在真实窗口里没有验证到。

**启动各阶段**（`performance.now()`，8 次启动的范围）：贴图 1.2 秒 → 渲染舞台 0.2 秒 → 船和货舱 0.1 秒 → 着色器预编译 0.8 秒 → 加载界面下先画两帧 1.5–2.6 秒 → 大厅出现（3.8–4.9 秒）。

## 3. 看过的画面

以下都是打开截图逐张看的，属于目视判断，不是数值：

- 大厅、货舱俯瞰、整条船（左舷船头方向）、船尾的驾驶室。
- 第一人称：出生舱、主甲板三个方向、两条通道、AWM 开镜、军刀、手雷、7 件武器各自的腰射 / 瞄准 / 侧后方特写。
- 清晨、白天、黄昏、夜晚四个时刻的第一人称画面。
- 阵亡、战绩板、结算三个覆盖层；900×600 的小窗口。
- 两队士兵各一张 2.5 米距离的正面近景，以及开镜 4 倍下的士兵。

看到并改掉的（按发现顺序）：景深默认开着，把枪和近处全糊了；枪被广角拉变形、没有高光像个玩具；集装箱上的锈痕大到盖住了标志；墙上的掉漆密得像雀斑；木箱像纸箱；天空里一朵云都没有（云量传进去是 `undefined`）；大厅里船又小又黑、还被一块巨大的“枪模”挡着；枪口的光把整面墙照成粉色；被击中后的红屏在冻结仿真里不褪。

## 5. 自己定的规则和数值（没有官方资料）

- 武器伤害、射速、弹匣、换弹时间、后坐、散布：按这些枪的常见设定和常见射击游戏的数值给的，不是原版的。
- 部位倍率头 ×4、腹 ×1.25、腿 ×0.75；护甲分担 28%；重生 3 秒；保护 2 秒；一局 10 分钟。
- AWM 两级放大 4 倍 / 8 倍，拉栓 1.25 秒。
- **连杀按一条命算**：不死就接着数，不看两次击杀隔了多久。搜过中英文资料，没有找到官方的判定说明，只有零星说法互相矛盾；这里按爆破模式里隔很久的击杀也会报连杀的印象定的。
- 机器人三档难度调的是反应时间（0.75 / 0.42 / 0.24 秒）、瞄准误差（4.2 / 2.6 / 1.4 度）、连发纪律、伤害倍率、视野。

## 6. 验证过程中发现并修掉的问题

这些是写自动化检查之后才暴露出来的，记在这里，因为它们说明“看着能跑”和“跑对了”是两回事：

| 问题 | 怎么发现的 | 修法 |
| --- | --- | --- |
| 玩家的枪口焰、火花、硝烟、血雾**不更新也不消失**，一直堆到把粒子池占满 | 浸泡测试里粒子数只涨不跌 | 重构枪口焰时漏掉了一行 `glow.update(dt); smoke.update(dt)`；补回来，并加了一条验收项「特效两秒内全部散尽」，浸泡测试也把“粒子池占满”算作失败 |
| 每重开一局，7 个士兵的骨骼贴图留在显存里不释放 | 浸泡测试发现回大厅后贴图数量多了 7 张 | 清场时一并 `skeleton.dispose()` |
| 景深在“自动”画质下默认开着 | 枪和近处全部发虚 | 默认关掉（第一人称里不需要） |
| 第 2 个连杀报成“三杀” | 验收项「连杀报双杀」不过 | 横幅取文字时差了一格 |
| 天空里没有云 | 外观截图 | 云量没有从关键帧传进着色器，算出来是 NaN |
| 自动画质把“显示器刷新慢”当成“显卡不够快” | 无头浏览器里开着开着就从高档掉到中档 | 改成拿这台显示器最快的帧间隔做基准，只有明显更慢才降档；人为把每帧拖慢 40 毫秒验证过它仍会降档 |
| 大厅里出现巨大的灰色团块 | 截图 | 为了预编译着色器提前造了枪模，开打之前它停在镜头原点 |
| 枪模单独成场景后完全看不见 | 枪模图鉴里一把枪都没有 | 把镜头的世界坐标抄给了枪模的根节点，而那个场景的镜头在原点 |
| 红屏、受击方向、横幅的淡出用的是 `setTimeout` | 冻结仿真截图里红屏不褪 | 改成按对局时间走 |

更早的时候（搭场景和玩法阶段）还修过：海面画在甲板的高度、`out` 是 GLSL 保留字、手臂和手指没有跟随变换（悬在原点立着）、寻路平滑化时死循环、身体那根胶囊的球形顶帽把爆头算成了打中身体、出生舱门口的箱子把门堵死、右墙的集装箱把船头舱的门洞挡住。

## 7. 没验证的

- **只在无头 Edge + RTX 3080 上跑过。** Firefox、Safari、集显、别的显卡都没有测。
- **本地显示器上的帧率没有量过。** 做测试时这台机器是远程桌面会话，虚拟显示器的刷新率是 32 Hz（`EnumDisplaySettings` 读到 `1920×1080 @ 32 Hz`），浏览器无头、有头都跟着这个节奏走——大厅也一样是 32 帧。所以帧率数字说明不了游戏本身的快慢；能量的是单帧渲染耗时和主线程各部分的耗时（对局逻辑约 1.2 毫秒、界面 0.4 毫秒、渲染提交 3–7 毫秒）。
- **声音没有听过。** 无头环境不出声；所有和声音有关的结论只有“代码跑了、没报错”。
- **指针锁定在真实窗口里只验证到“锁定成功”这一步**。无头环境里测的是拿不到锁定时拖动视角的退路；真实窗口里验证了点「开始游戏」后锁定成功。Esc 退出锁定再弹出暂停菜单、暂停后点「继续」重新锁定这两步，脚本模拟不了，没有亲手试过。
- **手感、难度、好不好玩**只能人来判断。

## 8. 做不到的

- 士兵和枪是圆角盒、圆柱、球拼的。两三米外看得过去，贴近了比商业游戏的模型简单得多：没有面部，手指是分节的手套，枪上没有厂牌和刻字。
- 没有动作捕捉，走跑、换弹、倒地都是程序算的姿势。
- 机器人是脚本 AI：会走位、找掩体、换弹，不会包抄、不会报点、不会配合。
- 只有团队竞技，只能和机器人打；没有联网、经济、买枪、配件。
- 不支持触屏。

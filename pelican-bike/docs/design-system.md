# 鹈鹕骑行：设计系统

这份文档记录**有意做出的决定**。之后改动页面前先读一遍：有些看起来“可以随手改”的数值，其实是整条链路的一环。

## 意图与视觉方向

- **观者该看到、感到什么**：一眼认出“一只鹈鹕在骑车”，然后想上手骑一段。情绪是轻松、温暖、安全的（cozy）。
- **造型语言**：玩具 / 赛璐璐动画。粗墨线、三阶色阶、圆角、低饱和的场景衬托高饱和的主角。
- **参考**：白鹈鹕与褐鹈鹕的侧面照（小头、S 形粗颈、极长的扁喙和下垂的喉囊、短橙腿蹼足、枕后冠羽）；巡航车照（奶油色气球胎、后掠车把、宽弹簧座、长挡泥板）。照片只用来观察比例，页面不分发任何照片。
- **主视角距离**：主体检视 3–7 m，特写 1–2.5 m，场景总览 200 m 以上。
- **被夸张的维度**：喉囊的深度（最深 0.175 m）。喙长与头长之比约 1.8（参考照片里目测约 1.9–2.3，基本相当）。其余尺寸尽量贴近参考比例，但没有逐项测量。

## 对象决定

### 鹈鹕（主角）

- **形体层级**：躯干（沿倾斜脊线放样的蛋形）→ 颈（逐帧重建的放样，平行传输标架）→ 头（椭球）。颈的根部埋进胸口、末端埋进头里，所以看不到接缝，也不需要焊接成一张皮。
- **喙与喉囊**：上喙是带脊的扁平放样，末端下钩并用顶点色染成红色；下颌 + 喉囊是另一个放样，截面**上下不对称**（上方是薄唇，下方最深 0.175 m）。两者同绕颌关节旋转来张口，口腔内用深红色楔形补面，避免张口时“看穿”。
- **腿与翅**：解析双骨 IK。髋在 (±0.165, 0.925, −0.235)，踝点在踏板轴上方 7.2 cm，大腿 0.39 m + 小腿 0.39 m。按这组尺寸算，上止点屈膝约 116°、下止点约 34°、全程最大约 117°（单元测试守住下止点 22°–48°、全程 ≤ 124° 的区间）。膝盖朝前偏外，肘部朝后偏外。
- **末端固定在车上**：蹼足是踏板的子节点，深色翼指是把套锚点的子节点——脚掌和“手指”永远贴着踏板与车把。
- **头部稳定**：头的目标位置只跟随躯干的平移、缩放和侧倾，**不跟随前倾**；再经过弹簧滞后，形成次级重叠动作。
- **刻意保留的分离件**：头盔、眼周裸皮、眉、冠羽、肘部飞羽、尾扇都是独立网格。在描边风格里，分离件各有轮廓线是风格的一部分。

### 自行车

- 巡航车几何：轴距 1.12 m、轮胎外半径 0.345 m、曲柄 0.17 m、中轴高 0.29 m。座垫顶面恰好贴着鹈鹕肚皮。
- 传动：44 齿牙盘、18 齿飞轮、三速花鼓（0.75 / 1.0 / 1.33）。链条是沿闭合回路（两条公切线 + 两段包角）滑动的实例化链节，踩踏时前进、滑行时静止。
- 转向总成绕头管轴旋转，转角来自路线曲率。

## 表现方式与事实依据

- **权威状态**：骑行速度（`core/ride.js`）。曲柄角、车轮转角、链条位移、HUD 读数、音乐节拍都由它导出，任何一处都不能单独驱动另一处。
- **物理的边界**：纵向运动是“目标速度 + 惯性 + 坡度”的简化模型（不是功率模型，没有风阻系数、没有 watts）。跳跃是独立的竖直抛体线。
- **太阳位置是艺术设定**，不是天文模型：方位与高度按时刻手工指定，只求氛围一致（阴影方向、天空色、灯光全场景一致）。页面不声称任何天文准确性。
- **参考过的事实**（用于造型，不构成页面里的声明）：鹈鹕有长而扁的喙、可扩张的喉囊、四趾全蹼的脚、短的腿；这些来自参考照片的观察。

## 质量目标与管线

| 对象 | 总览（> 15 m） | 检视（3–7 m） | 特写（< 2 m） |
| --- | --- | --- | --- |
| 鹈鹕 | 剪影可辨（喙 + 喉囊 + 头盔） | 关节连接自然，描边连续 | 眼睑、眉毛、喙尖红甲、下颌带、冠羽可辨 |
| 自行车 | 一眼是巡航车 | 车架、挡泥板、车筐、弹簧座、辐条 | 链节、链轮齿孔、把套 |
| 世界 | 岛形、灯塔、栈桥可辨 | 道具落地、描边随距离淡出 | 棕榈叶锯齿、编织纹理 |

- 构建路线：**全部自定义几何 + 自定义着色器**。没有使用任何现成模型或材质库。
- 世界地形高度只有一个权威函数（`terrainHeight`），地形网格、路面、道具落地、海水深度都从它取值。

## 材质、构图与尺度

- **色彩空间**：全程在显示色域做光照混合（`ColorManagement.enabled = false`，无色调映射）。赛璐璐的阴影是“固有色向蓝紫偏移并压暗”，在显示色域里调最直观；任何色调映射都会把硬边色阶揉软。
- **色阶**：明暗交界在 N·L ≈ 0.18–0.24（随时刻的调色盘变化），核心暗部在 N·L ≈ −0.28；边界宽度随屏幕导数自适应，斜面上不出现锯齿。
- **描边**：反面外扩，按屏幕像素定宽，默认 1.6 px，26–95 m 间淡出。硬边几何体用位置焊接后的平滑法线，否则棱角处会开裂。
- **调色盘**：时刻调色盘有 10 个关键帧（`core/palette.js`，首尾都是深夜以保证循环闭合），颜色和数值一起插值。场景饱和度低（≤ 约 45%），主角饱和度高。
- **夜景**：每盏路灯是地面上半径约 10 m 的一汪暖光，灯距 27 m，光斑之间留暗处；车灯占 0 号光源槽；灯塔光束是旋转的 1 号槽。光束用专用材质：沿长度渐隐、迎面更亮、单面。

## 行为与交互

- **状态机**：停车 / 踩踏 / 滑行 / 刹车。略高于目标速度 → 滑行（踏板回到水平）；明显高于 → 刹车；巡航时保持踩踏，让腿始终可读；下坡超速 → 自动滑行。
- **因果可见**：按车铃 → 附近海鸥爬升飞开；点海面 → 鱼跃出、水花、涟漪，鹈鹕转头看鱼；落地 → 尘土、镜头微震、喉囊晃动。
- **镜头**：跟拍（可拖动环绕、5 秒后自动回正）、侧跟、特写、环绕、导演（7 种机位自动切换并黑场过渡）、鹈鹕视角（隐藏会挡视线的头部部件，保留喙）。
- **暂停语义**：暂停冻结仿真与全局时钟；镜头仍可拖动；导演机位不再切换；任何改参数的操作不解除暂停。
- **减少动效**：遵循系统设置，也可在设置里手动开启。开启后开场不自动环绕、镜头不震、界面动画退化为透明度变化。
- **自动画质**：量的是**每帧真实耗时**（渲染后读回一个像素强制同步），不是帧率——刷新率低的屏幕不该被误判成性能不足。

## 运行与检视

- 运行时不联网：Three.js 与全部代码打包成一个传统 `<script>`，字体以 base64 内嵌（`file://` 下外链 CSS 字体会被跨域策略拦住）。
- 静态道具按弧长分 24 段合批（每段 1 次绘制 + 1 次描边），可被视锥剔除。
- `X` 键显示骨架：红色是腿、蓝色是翅与围巾、墨色圆圈是踏频轨迹。
- 调试接口 `window.__ride` 与 URL 参数用于直接进入某个状态。

## 写实画风与电影画质（默认画风，2026-11 第二轮）

**取舍**：用户要“3D 写实场景 + 电影画质”。几何不动（鹈鹕、自行车、环岛都是原来的程序化放样），换掉的是**光照、材质、大气和成像**这一整层；赛璐璐及两种纸面画风原样保留，`V` 循环切换。这样可以逐像素确认卡通画风没有被改坏。

- **大气是算出来的，不是调出来的**。`core/skymodel.js` 在球面地球上暴力积分出透射率查找表（高度 × 天顶角，含地球阴影和臭氧），`gfx/skyphys_glsl.js` 是同一套公式的 GLSL 版（单元测试比对常数与取样公式）。由此免费得到：正午偏白的日光、日落时橙红的直射光、太阳落下后高空仍被照亮的曙暮光、偏蓝的蓝调时刻。单次散射的天顶比实测暗 2–3 倍，补了一项颜色取瑞利系数比值的各向同性底光（经验系数 0.12）。
- **一张烘焙图三处用**：HDR 等距柱状图既是穹顶贴图，又是 PMREM 环境光（IBL 与天空严格同亮度），还是远处海面的反射源。太阳挪动不足阈值时不重复生成 PMREM。
- **材质靠查表而不是改调用处**：`gfx/pbrclass.js` 把“赛璐璐固有色 + 参数”映射成物理材质（铬、黄铜、漆面、清漆车漆、木材、树皮、叶片、羽毛、喙、眼、橡胶……），道具工厂一行没改。合批网格把（粗糙度、金属度、标记、清漆）写进逐顶点属性 `aPBR`，标记位在着色器里展开成树冠轮廓侵蚀、叶片背光透光、羽毛绒毛、白漆压暗。
- **雾是大气透视**：替换 three 的雾代码段，雾色取模型在背光方位低空的平均辐射，朝阳方位另取一色按视线混合；清晨加一层贴地雾。实体材质和海面用同一个公式，海平线才接得上。
- **倒影是真的**：海面用镜像相机把场景再画一遍（近裁剪面斜截到水面），灯塔、栈桥、棕榈、鹈鹕都在水里。“低”档关掉，只反射天空。
- **地表纹理必须跟着世界坐标走**：地形网格没有可用的 uv，草地 / 沙地 / 岩石按 XZ 投影、陡坡按朝向换平面，再叠两个尺度的明暗变化打散平铺感。
- **棕榈两套叶子**：赛璐璐画锯齿叶片，写实画沿叶轴排列的小叶卡片（透明裁形、双面、背光透光）。两者共用同一组随机数，形状严格对应，各自只在对应画风下显示。
- **电影画质 = 成像链，而不是滤镜叠满**：HDR 多重采样 → 环境光遮蔽 → 泛光（阈值在 1.0 以上，只有真正的 HDR 亮部发光）→ 景深（焦点跟主体，每个采样点用自己的模糊圆判断能否盖住中心，前景虚化会自然溢到清晰背景上）→ AgX → 显示色域的分离色调（暗部偏青、亮部偏暖）、饱和度、锐化、暗角、胶片颗粒（中间调最多）。AgX 输出偏灰，所以后面补了饱和度（1.34）和对比度（1.09）。
- **曝光按时刻给定，不做自动曝光**：正午 0.72、黄昏 0.95、蓝调 2.7、夜晚 7.0。夜光是“电影式夜景”（月光远比真实亮、夜空留底光）；体积光束的亮度按 1.6 / 曝光折算，才不会在夜景里过曝。
- **界面随画风换装**：写实画风下 `body.is-real` 把令牌换成深色玻璃（半透明面板、16 px 背景模糊、1 px 细线、暖橙强调），画面比 3:2 宽时按 2:1 加黑边，界面元素用 `--bar` 让开黑边。赛璐璐画风下纸白面板与 2 px 墨线不变。

**踩过的坑**（都在验收报告里）：
- GLSL ES 不对函数实参做 int → float 隐式转换：模板里插进 `7` 而不是 `7.0` 就编译失败。
- `#include` 在 `onBeforeCompile` **之后**才展开：要改 three 自带代码段（清漆 / 绒毛的逐顶点开关），必须改 `ShaderChunk` 本身。
- three 自带的 `BokehPass` 读的不是真实深度（示例着色器里是占位函数），景深自己写。
- 一帧里渲染多次场景（倒影、法线、深度）时，阴影贴图默认每次都重画：改成每帧开头置一次 `needsUpdate`。
- 换档后立刻测帧耗时会把多重采样缓冲区的重建算进去：标定前先预热 4 帧，并取两轮里较小的值。

# 深海王城：设计系统

本项目由 GLM-5.4 开发，提示词只有 README 末尾的那一句。这份文件记的是做下来的决定：想要什么、每样东西为什么长这样、靠什么撑住“写实”。

## 意图与视觉方向

一句话：**沉在四十米水下的一座王城，可以游进去看。**

- **看的人要有的感受**：安静、辽阔，有一点肃穆。光从很远的水面上斜着下来，城是旧的、被海接管了一半，但还认得出它当年的气派。
- **视觉上的一句话**：一座石头城坐在海床的台地上，城门朝南，一条石桥跨过潟湖；四周是珊瑚花园、巨藻林、沉船和村落，再往外是深渊。远处的城沉在蓝色的水里，近处的东西有颜色。
- **观看距离分三档**：巡游的远景（五十米外看整座城，靠轮廓和明暗立住）；潜泳的中景（十米上下，看砌块、彩窗、珊瑚的枝条）；贴到跟前的近景（石栏上的海绵、石像的脸、桥洞内顶面的附生生物）。三档各自要有东西看，所以细节分三层放：轮廓（几何）、表面（贴图和法线）、“长了东西”（附着层和散布的小生物）。
- **颜色**：整片是蓝青的水色；有颜色的是光带来的东西——彩窗透到地砖上的红黄、灯笼的青、珊瑚的橙紫、巨藻透光的金橄榄。颜色的饱和度跟着距离掉，远处只剩蓝。

## 对象决定

**王座厅**是最费心的一个对象，因为巡游在它里面待的时间最长。

- *轮廓*：哥特式的侧堂——带扶壁的侧墙、尖拱长窗、正门和山墙上的玫瑰窗、后殿的八边形鼓座、金肋穹顶。先用 `arch.js` 的积木（墙、窗、柱、扶壁、穹顶）搭，再在城堡这一层决定比例。
- *窗子*：两心拱是真正按几何画的（两个圆心都落在拱脚连线上），不是抛物线。窗花是一根大理石的中梃顶上一个小圆环。
- *彩窗*：六种花样（三叉戟、鲸、明珠、巨藻、太阳、拼花），每种是一张用 Canvas 画出来的图集格子：先画图案，再分成菱形的小块、加边框和圆珠、逐块画玻璃的高光、画铅条、最后挖掉几块、罩一层污垢。玫瑰窗单独一张。
- *光斑*：每扇带玻璃的窗登记一条记录，每帧把窗的轮廓沿日光方向投到地砖上，铺同一张图集的贴图，用“乘”混合——只有地砖上被太阳照到的像素才被染成玻璃的颜色。所以缺了玻璃的地方还是白光，铅条和窗花的影子还在。
- *王座*：金色的御座，靠背是一道尖拱，顶上一颗发亮的明珠，前面三级圆台阶，地砖上嵌一圈金环。屋里两道木屋架（系梁、宝顶柱、椽、檩）和三盏吊灯。

**石像**（门楼的守望者、喷泉上的小像、崖沿上的巨像共用一份几何）：一个拄着青铜三叉戟、左手托着明珠、戴王冠的蓄须海之王。身体不是零件拼起来的，是一个**符号距离场**（`statue.js`）：长袍（截面是椭圆，按高度查半宽）、腿、脚、肩、两条胳膊、十根手指、脖子、锁骨、头（颅顶、下颌、眉骨、挖空的眼窝、颧骨、鼻子、嘴唇、耳朵）、一绺一绺的大胡子和头发，各是椭球或圆台，用平滑的并集融成一整块；眼窝、嘴缝是平滑的减法挖出来的；衣褶（九道竖着的大褶，谷是尖的、脊是圆的）、胸肌、肚子、乳尖、肚脐是贴在表面上的起伏。然后用步进方格把这个场的零面网格化成石头：腰带以下是 3 厘米的格子，腰带以上的整个上身和握戟的右手是 1.5 厘米的格子（脸和手要细，袍子可以粗），细格子伸进粗格子里一段，断口藏在腰带底下和小臂上。法线取场的梯度，凹进去的地方（衣褶的沟、脖根、腋下、眼窝、胡子底下）用顶点色压暗。披风是两层的放样面料带卷边；王冠、腰带、从肩上斜到胯的扁带子、掌上的明珠、三叉戟是单独的件。一共约 20 万个三角形，算一次要半秒多。三处只是比例和颜色不同（0.92、0.42、5.2）。

**沉船**：船身是逐站画出来的曲面（船头尖、船尾平、舷侧上部内收），朝上的左舷被炮弹打穿一个洞，洞是按三角形挖的。桅杆、帆桁、索具、炮门、锚、舵、木桶都在。从破洞里滚出来的货物（七只陶罐、四个箍着铁的木桶、十块船板）按世界坐标摆在海床上。

**珊瑚**（14 种）：鹿角珊瑚是反复分叉的管子，末梢发白；桌珊瑚是一张起伏的圆桌；**脑珊瑚**的脊是真的几何——三维噪声的等值面在表面上鼓起一道道脊，沟里用顶点色压暗，大个的用高细分（84 × 46），小个的用低细分；管海绵的管口往里有内壁，看进去是黑的；海扇是带网孔的薄片；砗磲是两片带放射肋的壳，上面那片绕铰链张开，缝里一圈波浪形的外套膜；海星是五条臂长短不一的放样曲面，有一条臂的末梢卷着。

**巨藻**：一根细茎长到顶，沿茎按螺旋出六十来片窄长的叶子，每片叶子中间有一道折起的叶脉、边缘起皱、带一点扭转，根部有一个小气囊。

**鱼和大动物**：鱼群是三种体形（细长、侧扁、长条）的模板加实例色，一群共用一种体形和花色。鱼皮是细鳞或者竖着的深色条带。大动物（两只海龟、一条蝠鲼、一条鲨鱼、三群水母、一头抹香鲸）每个是一份手工几何，形变在顶点着色器里。

## 事实依据

光学部分按物理关系写，常数按观感定：

- **阳光折射进水里**：斯涅耳定律，折射率 1.333。太阳最多离竖直 48.6°，方位不变。
- **衰减**：Beer–Lambert 律，每个通道各算各的。视线的消光系数（红、绿、蓝）是 (0.094, 0.036, 0.020) 每米——60 米外蓝光还剩三成，红光基本没了。**这是有意偏保守的**：清澈外海在 40 米深处的真实吸收要狠得多，那样整座城只剩单色蓝，材料的颜色全看不见。
- **日光的逐通道吸收**取得很温和（相当于把光源的颜色校正回来），蓝调交给天光：背光处只有天光，红光掉到蓝光的三成。明暗两边不光是亮暗不同，色温也不同。
- **水色**：散射进视线的天光，闭式解；远处的水色只取决于光源和消光系数。
- **海面**：从水下往上看，正上方是一个约 97° 的斯涅尔窗，窗外是全反射镜面，按菲涅耳定律分配。
- **焦散**：波面把光聚散，亮度 = 1 / |雅可比行列式|。和水面、光束用的是同一组波（17 列深水波，24 米一个周期，每一列满足 ω² = g·k），所以三者永远对得上。
- **天空**：大气散射的物理模型，JS 和 GLSL 各一套实现，用测试比对（瑞利、米氏、透射率查找表、夜空的底光）。

**形态的依据**：巨藻（*Macrocystis*）的叶子和气囊、脑珊瑚的脊、砗磲的外套膜、两心拱、玫瑰窗、扶壁和哥特式侧堂的比例，都是照着真实的样子做的；尺寸和数量是估的。

**有意不像真的地方**：水比真实的清；月光比真实亮得多；灯笼的青色光和建筑的比例是创作；城、神庙、村落都是虚构的。

## 材质、构图与尺度

- **石灰岩**：一张铺 6 米 × 6 米的贴图，6 块宽 14 层高（一块 1.0 × 0.43 米）。每块石头有自己的色相、高低和倾斜，边缘被啃出缺口；面上有起伏和溶蚀的小坑，灰缝底下挂着水痕，有成片的藻膜和一簇簇的藤壶。
- **铺地**：抖动格子的 Voronoi，随机去掉两成格心，小板并成大板；缝是弯的，里面填着沙。
- **大理石**：乳白底，顺着石头一路游下去的灰色脉络，粗的主脉带一圈晕，再分出去几道细纹。
- **附着层**（`growth.js`）：挂在石头一类的材质上。朝上的面、背光的角落按世界坐标的三维噪声长出藻膜（深橄榄绿）和钙化藻的壳（粉紫）。顶点色的灰度倍率越小 = 风化得越厉害 = 长得越多。这是“沉了很久”的主要来源。
- **礁石**：八种“捏”出来的石头，用实例铺满海床。正二十面体细分之后沿半径按三个尺度的噪声推拉，再在噪声过零的地方压出褶皱，几个起伏的断裂面切出块面；底部压平。
- **散布**：每格最多一个点的抖动格子，带种子，所以每次打开都一样。
- **尺度**：潜泳的人半径 0.6 米，门洞宽 5.2 米、高 8.8 米，石栏高 1.25 米，王座厅的窗子宽 3.4 米、高 8.8 米。所有东西都是按米建的。

## 光照与成像

- **水下光照**（`waterlight.js`）挂在所有材质上：日光沿着折射后的太阳方向往下走，走到多深按 Beer–Lambert 律衰减多少，焦散回溯到水面上的入射点去取；天光按深度衰减；水体雾是逐通道的闭式解。
- **光束**：体积光，从阴影贴图出发沿视线步进，按“在不在光里”和到光源的距离积分。颜色按纯水对红光的吸收上色，远处的光束是深蓝的，不是白雾。
- **光斑**：见上。
- **后期**：HDR 多重采样 → 环境光遮蔽 → 光束 → 泛光 →（可选景深）→ AgX 色调映射 → 显示色域里的最后一道：色差、轻锐化、分离色调、饱和度、对比、暗角、胶片颗粒、电影黑边。眼睛适应负责时刻 × 深度的曝光。
- **画质三档**：流畅（无遮蔽、无多重采样、无倒影、光束很粗）、均衡、极致（4096 的阴影、4x 多重采样、1024 的焦散）。

## 行为与交互

- **三种状态**：标题（镜头在石桥南段的上空慢慢来回，看着南门）、电影巡游（16 个镜头，一共 169 秒，镜头之间黑场切换，每个镜头有一条路线和一个注视点，带一点手持的呼吸感）、自由潜泳（鼠标看、WASD 游、空格升 C 降、Shift 疾游）。
- **两种镜头之间切换时镜头留在原地**：从巡游切到潜泳，就是从当前画面接着往下游。
- **碰撞**：圆、墙段、方盒三种，从最近的一面把人挤出去；不能穿墙、不能钻进海床、不能浮出水面。
- **会动的东西**：鱼群和大动物沿着闭合的路线游；海扇、海鞭、海草、巨藻、海葵随涌浪摆，相位取自这一棵在世界里的位置；海洋雪在被城、桥、巨藻挡住的水里是暗的；几处冒泡口不停地放气泡，游泳的人隔几秒吐一口。
- **声音**全部用 WebAudio 现场合成：三层水声的底子、跟着泳速走的划水声、隔一阵响一声的鲸、沉船附近的木头和铁的呻吟、气泡、一层很轻的和声铺底。夜里更安静、更沉。
- **界面**：深蓝加一点毛玻璃的面板，强调色是灯笼的青色；罗盘、深度、地名、巡游字幕和进度；触屏有左边的摇杆和右边的升降、疾游。
- **自动画质**：每 45 帧看一次帧间隔的中位数，连续两次比这台机器的最快帧慢得多才降一档；稳定一会儿再升回去。

## 运行与检视

- 双击 `index.html` 就能打开（`file://`），不需要服务器，运行时不联网。
- `window.__game` 给自动化留了口子：换时刻、换水质、换画质、跳镜头、量帧耗、读状态。地址栏的参数（`?hour=night&clarity=hazy&q=1&mode=tour&shot=5&ui=0`）同样是为了这个。

## 踩过的坑

都在验证报告里记了因果，这里只留最值得记的几条：

- **厚墙里的斜光**：1.7 米厚的墙、窗子偏 42° 的时候，只有窗洞下半截能透光。侧墙减到 1.3 米、窗子开大、下午的太阳方位挪到离西墙法线 30°，光斑才成气候。
- **光斑被环境光遮蔽压黑**：光斑的三角形投影之后绕向是反的，在法线 / 深度的预通道里算出来的法线朝下。让它不进那个预通道。
- **灯光数量一变，着色器全部重编译**：灯笼的点光源按距离开关，数量在 1–10 之间变，每变到一个新数字画面卡两三秒。改成永远 10 盏都在，不用的强度置 0。
- **第一次看到的东西卡两三秒**：着色器等物体进视野才编译。加载画面里先把所有程序编译好（并行的扩展），再不裁剪地整体画一帧。
- **选了流畅档，几秒后被升回均衡**：“画质有没有被固定”用的是 true / false，而固定下来的档位 0（流畅）也是假值——自动画质的逻辑把它当成“没固定”，帧一快就升档。是性能表里“流畅档”的绘制次数和均衡档一样多才看出来的。固定与否和固定在哪一档分开：自动是 null。
- **顶点色和实例色乘了两遍**：巨藻的叶子变成了近黑色。实例色只留一点色差。
- **抖动格子的 Voronoi**：格心坐标带着列号和行号，算距离时又加了一遍，铺地的板缝乱七八糟。
- **石像像关节拼起来的木偶**：长袍、手臂、头各是各的放样曲面，肩和手臂之间有裂缝，袍子是根光滑的管子。改成写一个符号距离场再网格化，才有了衣褶和一整块石头的感觉。
- **粗细两套网格的接缝**：头用细格子、身子用粗格子，两边的面在同一个平面上对齐也不行——断口一圈是锯齿，脖子上像勒了一道。让细格子顺着脖子、小臂伸进粗格子里两格，伸进去的那一段把面往里收 5 毫米，粗面在外面接着，接缝就没了；腰带以上的整块上身干脆都用细格子，剩下的断口在腰带底下。
- **又窄又浅的沟在网格上是锯齿**：腹肌的横沟、胸肌下缘的沟只有 7–12 毫米深、5 厘米宽，贴近了看是一块块被啃过的黑斑（关掉阴影还在）。只留宽而缓的起伏。
- **近处影子的边缘是锯齿**：阴影盒半径 150 米，摊到 4096 的贴图上一格 7 厘米——礁石和柱子落在沙上的影子、胡子落在胸口上的影子，边缘一格一格的。收到 100 米（一格 4.9 厘米），对照截图里边缘干净了；100 米以外没有影子，那个距离已经沉在蓝色里。
- **长在石像上的东西浮在水里**：生长点是照着旧石像拍的坐标，换了几何以后一只桌珊瑚挂在脑袋旁边。改成按石像自己的坐标给，再用场把表面上的点找出来。
